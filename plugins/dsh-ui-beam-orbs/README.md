# dsh-ui-beam-orbs

DSH Web **界面皮肤层**插件：玻璃拟态（侧边栏/输入框/消息气泡/代码块/计划/任务/提问/审批卡片）+ Border Beam 状态机 + Thinking Orbs 动态指示器 + 任务清单 Pulse + 发送按钮微动效。

> 背景引擎（极光 / 粒子鲸鱼 / 星座网格 / 鼠标跟随交互）在 `dsh-ui-deepseek-bg` 插件，两插件配合使用获得完整效果。

## 安装

```bash
dsh plugin --profile web add dsh-ui-beam-orbs
```

重启后打开 http://127.0.0.1:3080 即可。

> 需 DSH ≥ 0.1.0-rc.8，Web profile 已含 `@deepseek-ai/dsh-web-app`。
