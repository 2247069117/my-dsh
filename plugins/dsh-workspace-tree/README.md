# @lynn123411/dsh-workspace-tree

DSH 工作区树：把左侧栏工作区从「工作区→会话」单层结构升级为基于真实文件系统推导的智能多级树形浏览器——会话环境严格隔离（会话 cwd = 所在目录），支持文件夹与工作区双模式、会话全局重命名、两阶段安全归档与全自动智能级联物理删除。

## 特性

- **文件夹模式**：按真实文件系统浏览目录，支持一键在任意目录新建会话（自动注册工作区，cwd 绑定）或新建子文件夹。
- **工作区模式**：按目录嵌套关系清晰组织所有工作区与会话列表，支持工作区折叠记忆与状态点聚合透传。
- **两阶段安全删除防护**：会话必须先移入归档才能执行永久删除，彻底防止工作区会话日常操作误删；在归档管理中永久删除时，自动递归级联清理其派生的全部 Subagent 子代理物理文件与注册关系，杜绝任何磁盘孤儿残留。
- **在 IDE 中打开工作区**：在每个工作区/目录的按钮栏提供一键在外部 IDE（VS Code、Cursor、Windsurf、Trae、WebStorm、IDEA、PyCharm、Zed、Sublime 或自定义命令）中打开对应工作区的功能。
- **配置自由**：在「设置 - 插件 - 工作区树」中自由配置默认打开的 IDE 或自定义启动命令、层级缩进、默认模式等。
- **全局会话重命名**：无论会话当前是否处于打开状态，均可通过 Host RPC 实时重命名。
- **归档管理与状态一致性**：提供多级递归归档视图，支持一键恢复与单条/批量永久删除，删除操作与 DSH 工作区数据库、内存实例及前端持久化墓碑四重强一致同步。
- **主题完美适配**：全面接入 DSH 设计系统，完美自适应浅色与深色主题。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-workspace-tree
```
