# @lynn123411/dsh-chat-tidy

Codex 级对话排版与工具调用标题智能翻译扩展插件。将 DeepSeek Harness Web 对话界面对齐专业级编码客户端的阅读节奏与信息密度，并提供轻量、非侵入式纯渲染层工具调用描述与报错信息的智能中文翻译，不污染会话上下文。

## 特性

- **Codex 级对话排版**：精准对齐桌面客户端的字体比例阶梯、行高、代码块间距与紧凑排版，阅读信息密度提升 20%。
- **非侵入式 DOM 挂载与双语对照**：彻底摒弃破坏性文本覆写，通过非侵入式包装保留原始 DOM 节点与 React Fiber 事件系统；支持点击译文就地在原文与中文之间无缝切换。
- **智能内容脱敏与占位符保护**：内置 `ContentMaskingPipeline` 管道，在发送翻译前对多行代码块、内联代码、URL 链接、文件路径及 CLI 命令行参数进行精准占位符脱敏与鲁棒还原，杜绝代码与路径被误翻译。
- **视口懒加载与流式防抖**：引入真实 `IntersectionObserver`（150px 缓冲区）与 400ms 流式打字防抖，仅对视口内可见元素触发翻译，彻底避免流式输出期间的残缺请求风暴。
- **工具调用标题与报错自动翻译**：仅在渲染层将工具调用动作描述（如 `Locate DSH home directory structure`）与失败报错（如 `bash: line 1: rm: command not found`）自动翻译为中文，正常调用参数与输出严格保持原样。
- **免 Key 直连翻译通道**：内置微软 Bing 网页翻译接口（免 Key、国内直连、无需任何外部服务），零配置即用。
- **智能调度与熔断保护**：1–100 动态并发限流队列、2000ms 硬超时中断、连续失败 3 次触发 30s 熔断自愈状态机、在途相同请求合并去重、7 天严格 LRU 双级缓存（Client `localStorage` + Host 磁盘持久化）。
- **设置页与快捷开关集成**：在会话顶部栏提供一键快捷开关，在「设置 - 聊天排版」中提供总开关、并发数调节、以及可选的「翻译思维链（Think 块）」开关（默认关闭），支持跨标签页状态强一致同步。
- **Think 负载保护与流式渐进**：思维链长文本按行分块（≤600 字符/块、上限 60 块），逐块流式渐进渲染；超长部分安全降级保留原文。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-chat-tidy
```
